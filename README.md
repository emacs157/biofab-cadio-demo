# BioFab — Cadio demo

The live squad-biomarker dashboard, as a single self-contained page.

**Simulated training session — demonstration data.** No hardware, no network, no
live patient or athlete readings. The physiology is a scripted simulation.

Served at `demo.biofab.co.uk`. Source of truth for this file is the private
`cadio` repo (`web/index.html`); this repo exists only to host the page, and is
updated by `web/publish.sh` there. Do not edit `index.html` here directly.
